# AstrBot Plugin Shittim · 什亭之枢

> 让驻留在什亭之匣中的智能体，在基沃托斯——不，在 QQ 中自由活动。

`astrbot_plugin_shittim` 是一个为 AstrBot 设计的插件，旨在让一个拥有统一人格与完整上下文的智能体，能够自主决定**说什么、对谁说、什么时候说**。它不再只是一个被动回复的机器人，而是一个拥有自己生活节奏、可以跨会话行动、会休息也会醒来的“生命体”。

---

## 设计理念

### 思考与发送分离

传统聊天机器人是“收到消息 → 生成回复 → 发回原会话”。  
什亭之枢把这条链路拆成两层：

- **思考层**：由大模型决定“现在该不该说话、该对谁说、该说什么”。
- **执行层**：由插件负责把消息准确投递到任意私聊或群聊，并维护全局状态。

这样，智能体才能真正做到“私聊里被叫去群聊发通知”，或者“在群里被叫去私聊某个人”。

### 生命节奏

她不是 24 小时待命的客服。  
她可以有自己的休息时间。在休息期间，所有消息不会被丢弃，而是进入队列；醒来后，她会一并处理堆积的对话，决定回复谁、怎么回。她甚至可以自主延后或提前休息，并在睡前向正在聊天的人道晚安。

### 统一灵魂，全域上下文

无论谁在私聊她，或者在哪个群聊里和她说话，她始终是同一个人。  
插件会维护一个全局的上下文池，让所有会话共享同一份人格记忆与近期摘要。她的“神秘”不会被会话边界割裂。

---

## 核心特性

- **全局状态机**：清醒 / 休息 / 起床处理中，状态跨所有会话共享。
- **自主作息**：支持设定休息时段，休息期间拦截 LLM 请求，消息进入持久化队列。
- **起床批处理**：休息结束后，将堆积消息摘要后一次性交给 LLM，由她决定回复策略。
- **跨会话上下文**：所有会话共享同一人格与记忆，不再“换个群就失忆”。
- **LLM 自主发送**：通过 `@filter.llm_tool` 注册 `send_message` 工具，让模型自主选择目标会话。
- **主动消息写回历史**：主动发出的消息会手动写入对应会话历史，避免她“忘记自己说过”。
- **作息微调**：支持 `set_rest_time`、`delay_rest`、`advance_rest`，让她自己决定何时休息。
- **睡前告别**：进入休息前，可自动向当前活跃会话发送晚安类消息。

## 使用示例

### 私聊叫她到群里发通知

> **你（私聊）**：爱丽丝，去群里发一下今晚八点开会。  
> **她**：好，我这就去。  
> *（她自主调用 `send_message`，向配置中的群聊发送通知）*

### 群里叫她私聊某个人

> **你（群聊）**：爱丽丝，私聊提醒一下小明交作业。  
> **她**：收到。  
> *（她自主调用 `send_message`，向小明发起私聊）*

### 休息与起床

> **她（23:30）**：我先休息了，晚安。  
> *（进入休息状态，所有消息进入队列）*  
> **她（07:00）**：早上好，我回来了。昨晚有人找我吗？  
> *（她读取队列，逐条决定是否回复、如何回复）*
