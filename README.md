# AstrBot Plugin Shittim · 什亭之枢

> 让驻留在什亭之匣中的智能体，在基沃托斯——不，在 QQ 中自由活动。

`astrbot_plugin_shittim` 让一个拥有统一人格与完整上下文的智能体，能够自主决定**对谁说、在哪个会话说、什么时候说**。它不是等着被 @ 的应答机：会按自己的性格和记忆判断该不该接话，能跨会话走动，也会在确实无话可说时安静待着。

---

## 设计理念

### 思考与发送分离

传统插件是「收到消息 → 生成回复 → 发回原会话」。什亭之枢把这条链路拆开：

- **决断层**：先判断这条消息值不值得回应，不值得就让官方 LLM 完全不触发（`stop_event`）。
- **主脑**：只在决定要回应时才生成回复，负责「怎么说」。
- **行动层**：由插件负责把话准确投递到任意私聊或群聊，并维护她「现在在哪」。

### 像人一样挑时机

人不会对每一句话都做一次判断。听到一句话先等对方把这段说完，再决定要不要接；判断不接就安静一阵。

插件也是这么做的：群聊里的普通消息先在**巡检窗口**里攒几秒，攒够了再整体判一次。这既省下大量模型调用，也让判定有完整语境——单看一句「应该可以」，模型根本不知道在说什么。

判定时她看到的是：**自己的人格、永久记忆、按话题召回的相关记忆、其它会话刚发生的事，以及这段对话之前紧邻的几句**。判断的不是「有没有人叫我」，而是「这段话里有没有我想接的东西」——参与是常态，沉默只留给纯刷屏和别人之间的私事。

### 统一灵魂，全域上下文

无论谁在私聊她、在哪个群聊和她说话，她始终是同一个人。

所有会话的消息进同一本**短期账本**，并构成她**唯一的上下文——一条全局时间线**：她说过的话就是她说的话，别人的话标着「在哪儿、谁说的、多久前」。所以**切会话不换记忆**，只是换了个说话对象；长期记忆跨会话共享。人格不会被会话边界割裂。

## 核心特性

- **接管官方 LLM**：所有消息先记账，再由规则层与巡检窗口决定是否放行主脑。要回应就置位唤醒标志放行，不回应就拦下，官方 LLM 完全不被触发。
- **按人格与记忆接话**：判定层会读入当前人格提示词、永久记忆与按话题召回的长期记忆，再结合窗口前文判断「有没有想接的东西」。默认倾向参与，不必等到被点名；纯刷屏、复读、表情和别人的私事才沉默。
- **群聊巡检**：不逐条判定，而是攒一小段（默认安静 5 秒、最多等 20 秒）整体判一次；判为不回则该会话安静一阵（默认 60 秒）。
- **私聊防抖**：私聊一定要回，但先等对方说完——最后一条之后安静满 10 秒才开口。一句话被拆成几条发时，她不会抢在中间插嘴。
- **噪声不进模型**：整段只有图片/表情、整段复读、同一人连刷短句，直接拦下——既省调用，也不让她因此沉默一分钟。
- **跨会话穿梭**：`list_sessions` 看有哪些地方可去，`peek_session` 先看那边的语境，`say` 过去说话，`leave_session` 离开，`rest` 全体静默。说完她就「在」那边了。
- **翻旧账**：`peek_session` 只看当下，`search_history` 按关键词翻聊天记录——已经清空、已经压进摘要的那些也能找回来。她不需要把一切都记在脑子里，只要记得去哪儿翻。
- **推迟入睡**：`delay_sleep` 让今晚晚点睡，入睡与起床一起顺延（受起床上限约束），只对当次有效，明天照常。
- **说在那边，不在这边**：她去别的会所说的话不会被搬回原会话复述一遍。
- **三层记忆**：
  - *短期账本*：跨会话原始消息，带来源与时间标记，防止把 A 群的话回到 B 群。条目超阈值时自动把最旧的一批压成摘要，别让上下文无限变长。
  - *长期记忆*：由独立的轻量模型在压缩时顺带产出，排在一条**位置榜**上——每晚整理产出的、每次被想起的都上浮到前，用得少的自然沉下去、逐级变模糊、最终被遗忘。
  - *永久记忆*：被反复用到或被她明确要求记住的，不排榜、不降级、不遗忘。
- **记忆注入按读取顺序**：永久记忆 → 榜前 10 条正文 → 其后 30 条关键词索引（提示她「还忘了什么」，需要时自己 `recall`）→ 全局时间线 → 当前消息 → 作息事件提示。
- **图片转文字**：AstrBot 给图片的只有「[图片]」占位，插件自己问一次视觉模型，把描述写回账本，于是判定、语境、页面都能「看见」那张图。
- **记忆页面**：WebUI 插件页里查看短期账本（含摘要块）与各层记忆，含图片描述、榜上名次与档位、标签、最近想起的时刻，以及当前作息（阶段 / 入睡与起床时刻 / 上次整理）。
- **风控**：目标白名单 + 每分钟/每小时限流。

## 架构概览

### 五条链路

**拦放链路（接管官方 LLM）**

```
所有消息 → 记入短期账本 + 刷新该会话焦点 → 决断层规则层
  ├─ 上游指令 / 被点名 / 无文本 → 当场定夺
  ├─ 私聊 → 要回，但先进静默窗口：安静满 10 秒才放行主脑
  └─ 群聊里的普通消息 → 巡检窗口：攒一小段对话再判一次
       · 判据 = 人格 + 永久记忆 + 相关召回 + 其它会话近况 + 本会话前文 + 窗口内容
       ├─ 不回 → stop_event()，官方 LLM 完全不触发，该会话安静一阵
       └─ 要回 → 置位唤醒标志，放行主脑生成回复
```

**焦点链路（她在哪）**

她可以同时在多个会话里「在场」，像一个人同时开着几个聊天窗口。收到某会话的消息 → 该会话获得焦点；安静超过 N 分钟 → 焦点失效（她休息了）。焦点**只约束主动发言**：被动接话永远不受限，任何消息都能唤醒她。

**记忆链路**

短期账本 → 条目**超阈值就压一轮**（按条数触发，不按时间；同一次调用产出「1 条摘要 + N 条长期记忆」）→ 长期记忆排在**位置榜**上 → 降级/遗忘/晋升/合并。图片消息额外走一次视觉转述，描述回填账本。

主脑读到的上下文就是账本本身：所有会话按时间排成**一条全局时间线**，切会话不换记忆，只换说话对象。深睡整理把当天账本收口清空后，时间线从零重新累积——前几天的事由长期记忆承载（当天的经历先被压成一条**当天摘要**写进榜最前）。

**作息链路与深睡整理**

清醒 / 浅睡 / 深睡三态，睡眠期只放行命令、被叫醒后进入清醒宽限。深睡期每晚整理一次：降级 → 遗忘 → 晋升 → 合并 → **短期收口**（树状压成一条当天摘要并写进榜最前）→ 清空当天账本 → 按保留期清理。收口与清空只在深睡期做，清醒期的兜底整理只跑维护——否则等于当场失忆。长期记忆按**榜上名次**逐级变模糊（榜前 60% 完整、到 85% 精简、之后只剩关键词），每次被召回就上浮回榜前；沉到榜尾再叠加「降级次数 + 连续未召回」才遗忘。`forget` 工具可以让某件事被明确忘掉且不再被重新记住。

**行动链路（跨会话穿梭）**

`list_sessions` 看有哪些会话 → `peek_session` 看那边的语境 → `say` 过去说一句 → `leave_session` / `rest` 离开。

## 使用示例

### 私聊让她去群里说一声

> **你（私聊）**：爱丽丝，去群里说下今晚八点开会。
> **她**：好，我这就去。
> *（她调用 `list_sessions` 找到群、`say` 过去说了话，然后留在那边；不会跑回来汇报）*

### 群里让她私聊某个人

> **你（群聊）**：爱丽丝，私聊提醒一下小明交作业。
> **她**：收到。
> *（她调用 `say`，目标 session 填小明的 QQ 号）*

### 她主动记住一件事

> **你**：以后提到「小蓝」就是指我。
> **她**：*（调用 `remember` 工具，这条记忆晋升为永久，不会衰减）*

## 配置

配置项在 AstrBot WebUI 的插件配置页，按功能分组：

- **memory**：记忆开关、压缩模型、**压缩阈值与批大小**、**全局时间线的 token 预算**、跨会话语境的配额（仅供决断层与巡检）、榜前正文与关键词索引的条数、图片转文字（是否启用、用哪个视觉模型、单条最多转述几张）、位置榜的遗忘门槛与晋升条件。
- **decision**：是否接管对话、决策模型（判定时会自动读取当前人格与记忆，无需单独配置）、私聊与点名是否直接放行、唤醒词、判定时每个会话带入的近期消息条数（也用于补窗口前文）、**私聊防抖时长**，以及**群聊巡检**参数（窗口时长、封顶时长、冷却时长、噪声预过滤）。
- **focus**：会话安静多久收回主动发言资格、主动发言前是否必须持有焦点。
- **schedule**：入睡与起床时间、起床上限、深睡阈值、叫醒信号门槛与清醒宽限、每日整理开关与兜底间隔、账本清理开关与归档保留天数。
- **proactive**：是否允许主动发言、目标白名单、每分钟/每小时限流、离开后是否还回原会话收尾。

## 安装

1. 在 AstrBot WebUI 的插件市场搜索安装，或把本目录放进 `data/plugins/`。
2. 重启或重载插件。
3. 至少配置一个**轻量决策模型**（`decision.provider_id`，留空则复用记忆压缩模型）。想让她看得见图片，还需要一个支持图片输入的**视觉模型**（填 `memory.vision_provider_id`，或直接配好 AstrBot 全局的「图片转述模型」）。
4. 插件详情里会多出一个「什亭之枢」页面，用于查看她的记忆。
